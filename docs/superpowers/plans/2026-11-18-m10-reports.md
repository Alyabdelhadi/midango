# M10 Reports Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A venue manager opens **Reports** in Midango Business, picks a period (last 7 days, last 4 weeks, last 3 months, or dates), and sees: headline numbers (bookings, how full the courts were, cash taken, no-show rate), an **occupancy heatmap** (weekday × hour), and **cash taken by court and week**.

**Architecture:** One read endpoint, `GET /venue/reports`, computes everything in memory from the period's bookings (a venue has at most a few thousand bookings in 92 days). Occupancy = booked court-minutes ÷ open court-minutes, both counted in 15-minute steps on the venue's wall clock, bucketed by weekday and hour; the business day (16:00 → 02:00) is respected, so a 00:30 booking lands in the next weekday's 00:00 hour, as the venue experiences it. Cash = the `cash_collected` taken at check-in (M7), grouped by court and by week (weeks start on Sunday, the Saudi work week). The UI is a page of tiles, an HTML-table heatmap and a plain table — no chart library.

**Tech Stack:** .NET 10 · React 19 · TypeScript. No new dependencies.

**Project rules:** No automated tests; Task 3 is a scripted API run (with SQL to move bookings into the past) plus a browser walkthrough. Every string in English and Arabic. Chart rules (dataviz method): one sequential hue (navy, light → dark) for occupancy; every cell also prints its percentage so colour is never the only carrier; a legend shows the scale; each cell has a hover title; the heatmap *is* a table, so a table view exists by construction.

**Decisions this plan locks in:**

| Topic | Decision | Why |
|---|---|---|
| Who | Venue manager only | Money and performance figures |
| Period | Default last 28 days to today; max 92 days | Enough for a quarter; bounded work |
| Occupancy counts | Confirmed bookings (checked in or not). No-shows, cancellations and blocks don't count as booked | A no-show freed the court (M7); blocks aren't sales |
| Open time | Opening hours × active courts today | ponytail: courts added or hidden mid-period distort old weeks slightly |
| Heatmap rows/columns | Rows Sunday → Saturday; columns are hours starting at the earliest opening hour, wrapping past midnight | Reads like the venue's day |
| No-show rate | no-shows ÷ (played + no-shows); played = confirmed bookings that have ended | Bookings still ahead aren't outcomes yet |
| Cash | Sum of `cash_collected` by court and week | What the till should hold |

## Endpoint delivered

`GET /venue/reports?from=YYYY-MM-DD&to=YYYY-MM-DD` (venue-manager) →
`{from, to, currency, dayStartHour, bookings, occupancyPercent, cashCollected, checkIns, played, noShows, noShowRatePercent, lateCancellations, venueCancellations, heatmap[{day, hour, percent, bookedMinutes, openMinutes}], cash[{weekStart, courtId, courtNameEn, courtNameAr, cash, checkIns}]}` · 400 bad range · 403 desk staff.

```csharp
using System.Security.Claims;
using Microsoft.EntityFrameworkCore;
using Midango.Api.Data;
using Midango.Api.Identity;

namespace Midango.Api.Bookings;

/// The manager's look back: how full the courts were, the cash taken and how many people didn't show up.
public static class ReportEndpoints
{
    public const int MaxDays = 92;
    private const int Step = 15;

    public sealed record HeatCellDto(DayOfWeek Day, int Hour, int Percent, int BookedMinutes, int OpenMinutes);

    public sealed record CashRowDto(DateOnly WeekStart, Guid CourtId, string CourtNameEn, string CourtNameAr, decimal Cash, int CheckIns);

    public sealed record ReportDto(
        DateOnly From, DateOnly To, string Currency, int DayStartHour,
        int Bookings, int OccupancyPercent, decimal CashCollected, int CheckIns,
        int Played, int NoShows, int NoShowRatePercent, int LateCancellations, int VenueCancellations,
        IReadOnlyList<HeatCellDto> Heatmap, IReadOnlyList<CashRowDto> Cash);

    public static void MapReportEndpoints(this IEndpointRouteBuilder app)
    {
        app.MapGet("/venue/reports", async (
            DateOnly? from, DateOnly? to, ClaimsPrincipal user, MidangoDb db, TimeProvider clock, CancellationToken ct) =>
        {
            var venue = await db.Venues.AsNoTracking().SingleAsync(v => v.Id == user.StaffVenueId()!.Value, ct);
            var zone = VenueClock.Zone(venue);
            var hours = await db.OpeningHours.AsNoTracking().Where(h => h.VenueId == venue.Id).ToListAsync(ct);
            var now = clock.GetUtcNow();
            var last = to ?? Slots.BusinessDay(VenueClock.ToLocal(now, zone), hours);
            var first = from ?? last.AddDays(-27);
            if (last < first || last.DayNumber - first.DayNumber >= MaxDays)
                return ApiErrors.Fail(400, $"Choose a period of up to {MaxDays} days.");

            var windowFrom = VenueClock.ToInstant(Slots.DayWindow(first, hours).From, zone).ToUniversalTime();
            var windowTo = VenueClock.ToInstant(Slots.DayWindow(last, hours).To, zone).ToUniversalTime();
            var rows = await db.Bookings.AsNoTracking()
                .Where(b => b.VenueId == venue.Id && b.Kind == BookingKind.Booking
                            && b.StartsAt >= windowFrom && b.StartsAt < windowTo)
                .Select(b => new { b.CourtId, b.StartsAt, b.EndsAt, b.Status, b.CheckedInAt, b.CashCollected, b.LateCancellation, b.CancelledByVenue })
                .ToListAsync(ct);
            var courts = await db.Courts.AsNoTracking().Where(c => c.VenueId == venue.Id)
                .OrderBy(c => c.SortOrder).ThenBy(c => c.NameEn)
                .Select(c => new { c.Id, c.NameEn, c.NameAr, c.Active }).ToListAsync(ct);
            var activeCourts = courts.Count(c => c.Active);

            // Court-minutes per weekday and wall-clock hour, counted in 15-minute steps.
            var open = new int[7, 24];
            var booked = new int[7, 24];
            for (var day = first; day <= last; day = day.AddDays(1))
            {
                if (Slots.Period(day, hours) is not { } p) continue;
                for (var t = p.Opens; t < p.Closes; t = t.AddMinutes(Step)) open[(int)t.DayOfWeek, t.Hour] += Step * activeCourts;
            }
            var confirmed = rows.Where(r => r.Status == BookingStatus.Confirmed).ToList();
            foreach (var b in confirmed)
            {
                var end = VenueClock.ToLocal(b.EndsAt, zone);
                for (var t = VenueClock.ToLocal(b.StartsAt, zone); t < end; t = t.AddMinutes(Step)) booked[(int)t.DayOfWeek, t.Hour] += Step;
            }

            var heatmap = new List<HeatCellDto>();
            int openTotal = 0, bookedTotal = 0;
            for (var d = 0; d < 7; d++)
            for (var h = 0; h < 24; h++)
            {
                if (open[d, h] == 0) continue;
                openTotal += open[d, h];
                bookedTotal += booked[d, h];
                heatmap.Add(new HeatCellDto((DayOfWeek)d, h, Percent(booked[d, h], open[d, h]), booked[d, h], open[d, h]));
            }

            // Weeks start on Sunday; a booking belongs to its business day (00:30 is still last night).
            var checkedIn = rows.Where(r => r.CheckedInAt is not null).ToList();
            var cash = checkedIn
                .GroupBy(r =>
                {
                    var day = Slots.BusinessDay(VenueClock.ToLocal(r.StartsAt, zone), hours);
                    return (WeekStart: day.AddDays(-(int)day.DayOfWeek), r.CourtId);
                })
                .Select(g =>
                {
                    var court = courts.First(c => c.Id == g.Key.CourtId);
                    return new CashRowDto(g.Key.WeekStart, court.Id, court.NameEn, court.NameAr, g.Sum(r => r.CashCollected ?? 0), g.Count());
                })
                .OrderBy(r => r.WeekStart).ThenBy(r => courts.FindIndex(c => c.Id == r.CourtId))
                .ToList();

            var played = confirmed.Count(r => r.EndsAt <= now);
            var noShows = rows.Count(r => r.Status == BookingStatus.NoShow);
            return Results.Ok(new ReportDto(
                first, last, venue.CurrencyCode, hours.Count == 0 ? 0 : hours.Min(h => h.Opens.Hour),
                confirmed.Count, Percent(bookedTotal, openTotal), checkedIn.Sum(r => r.CashCollected ?? 0), checkedIn.Count,
                played, noShows, Percent(noShows, played + noShows),
                rows.Count(r => r.Status == BookingStatus.Cancelled && r.LateCancellation),
                rows.Count(r => r.Status == BookingStatus.Cancelled && r.CancelledByVenue),
                heatmap, cash));
        }).RequireAuthorization(Policies.VenueManager);
    }

    private static int Percent(int part, int whole) => whole == 0 ? 0 : Math.Min(100, (int)Math.Round(100.0 * part / whole));
}
```

```tsx
import { useState } from 'react';
import { Field } from '../components/Field';
import { Notice } from '../components/Notice';
import { PageHeader } from '../components/PageHeader';
import { api } from '../lib/api';
import { useI18n } from '../lib/i18n';
import { addDays, formatDay } from '../lib/time';
import { DAY_KEY, DAYS, type Report, type Today } from '../lib/types';
import { useLoad } from '../lib/useLoad';
import type { MessageKey } from '../locales/en';

type Range = 'week' | 'month' | 'quarter' | 'dates';
const RANGES: [Range, MessageKey, number][] = [
  ['week', 'rangeWeek', 7],
  ['month', 'rangeMonth', 28],
  ['quarter', 'rangeQuarter', 91],
  ['dates', 'filterDates', 0],
];

export function ReportsPage() {
  const { t } = useI18n();
  // The venue's business day, so the periods end where the Today page says "today" is.
  const today = useLoad(() => api<Today>('/venue/today'));
  if (today.error) {
    return (
      <div className="page">
        <Notice tone="error">{today.error}</Notice>
      </div>
    );
  }
  if (!today.data) return <p className="page-loading">{t('loading')}</p>;
  return <ReportsView today={today.data.date} />;
}

function ReportsView({ today }: { today: string }) {
  const { t } = useI18n();
  const [range, setRange] = useState<Range>('month');
  const [from, setFrom] = useState(addDays(today, -27));
  const [to, setTo] = useState(today);
  const days = RANGES.find(([r]) => r === range)![2];
  const period = range === 'dates' ? { from, to } : { from: addDays(today, 1 - days), to: today };

  return (
    <div className="page">
      <PageHeader title={t('navReports')} />
      <div className="filter-bar">
        <div className="chip-row" role="radiogroup" aria-label={t('navReports')}>
          {RANGES.map(([value, label]) => (
            <label key={value} className="check-chip">
              <input type="radio" name="range" checked={range === value} onChange={() => setRange(value)} />
              {t(label)}
            </label>
          ))}
        </div>
        {range === 'dates' && (
          <>
            <Field label={t('fromTime')}>
              <input type="date" required value={from} onChange={(e) => e.target.value && setFrom(e.target.value)} />
            </Field>
            <Field label={t('toTime')}>
              <input type="date" required value={to} onChange={(e) => e.target.value && setTo(e.target.value)} />
            </Field>
          </>
        )}
      </div>
      <ReportBody key={`${period.from}|${period.to}`} from={period.from} to={period.to} />
    </div>
  );
}

function ReportBody({ from, to }: { from: string; to: string }) {
  const { t, money } = useI18n();
  const report = useLoad(() => api<Report>(`/venue/reports?from=${from}&to=${to}`));
  if (report.error) return <Notice tone="error">{report.error}</Notice>;
  if (!report.data) return <p className="page-loading">{t('loading')}</p>;
  const r = report.data;

  return (
    <>
      <div className="tiles">
        <Tile label={t('tileBookings')} value={String(r.bookings)} />
        <Tile label={t('tileOccupancy')} value={`${r.occupancyPercent}%`} />
        <Tile label={t('tileCashTaken')} value={money(r.cashCollected, r.currency)} note={t('checkInsNote', { n: r.checkIns })} />
        <Tile
          label={t('tileNoShowRate')}
          value={`${r.noShowRatePercent}%`}
          note={t('noShowOf', { n: r.noShows, m: r.played + r.noShows })}
        />
      </div>
      <p className="page-intro">{t('cancellationsLine', { late: r.lateCancellations, venue: r.venueCancellations })}</p>
      <Heatmap report={r} />
      <CashTable report={r} />
    </>
  );
}

function Tile({ label, value, note }: { label: string; value: string; note?: string }) {
  return (
    <div className="tile">
      <span className="tile-label">{label}</span>
      <span className="tile-value">{value}</span>
      {note && <span className="tile-note">{note}</span>}
    </div>
  );
}

const pad = (h: number) => `${String(h % 24).padStart(2, '0')}:00`;

/** Weekday × hour, one navy hue light → dark; every cell prints its percentage and has a hover title. */
function Heatmap({ report: r }: { report: Report }) {
  const { t } = useI18n();
  const cells = new Map(r.heatmap.map((c) => [`${c.day}|${c.hour}`, c]));
  // Hours the venue is ever open, starting at its earliest opening hour and wrapping past midnight.
  const hours = [...new Set(r.heatmap.map((c) => c.hour))].sort(
    (a, b) => ((a - r.dayStartHour + 24) % 24) - ((b - r.dayStartHour + 24) % 24),
  );
  if (hours.length === 0) return null;

  return (
    <section className="card">
      <h2>{t('heatmapTitle')}</h2>
      <p className="page-intro">{t('heatmapIntro')}</p>
      <div className="heatmap-scroll">
        <table className="heatmap">
          <thead>
            <tr>
              <th scope="col">{t('day')}</th>
              {hours.map((h) => (
                <th key={h} scope="col">
                  <bdi dir="ltr">{pad(h)}</bdi>
                </th>
              ))}
            </tr>
          </thead>
          <tbody>
            {DAYS.map((day) => (
              <tr key={day}>
                <th scope="row">{t(DAY_KEY[day])}</th>
                {hours.map((h) => {
                  const c = cells.get(`${day}|${h}`);
                  if (!c) {
                    return (
                      <td key={h} className="heat-closed">
                        {t('closedDay')}
                      </td>
                    );
                  }
                  const title = t('heatCell', {
                    day: t(DAY_KEY[day]),
                    from: pad(h),
                    to: pad(h + 1),
                    pct: c.percent,
                    booked: c.bookedMinutes,
                    open: c.openMinutes,
                  });
                  return (
                    <td
                      key={h}
                      title={title}
                      className={c.percent >= 50 ? 'heat-dark' : undefined}
                      style={{ backgroundColor: `rgb(7 19 41 / ${0.06 + 0.94 * (c.percent / 100)})` }}
                    >
                      {c.percent}%
                    </td>
                  );
                })}
              </tr>
            ))}
          </tbody>
        </table>
      </div>
      <div className="heat-legend" aria-hidden="true">
        <span>0%</span>
        <span className="heat-legend-ramp" />
        <span>100%</span>
      </div>
    </section>
  );
}

/** Weeks down, courts across, totals on both edges. */
function CashTable({ report: r }: { report: Report }) {
  const { t, lang, name, money } = useI18n();
  if (r.cash.length === 0) {
    return (
      <section className="card">
        <h2>{t('cashTitle')}</h2>
        <p className="empty">{t('noCash')}</p>
      </section>
    );
  }
  const courts = [...new Map(r.cash.map((c) => [c.courtId, { nameEn: c.courtNameEn, nameAr: c.courtNameAr }])).entries()];
  const weeks = [...new Set(r.cash.map((c) => c.weekStart))];
  const cell = (week: string, courtId: string) => r.cash.find((c) => c.weekStart === week && c.courtId === courtId)?.cash ?? 0;
  const weekTotal = (week: string) => r.cash.filter((c) => c.weekStart === week).reduce((s, c) => s + c.cash, 0);
  const courtTotal = (courtId: string) => r.cash.filter((c) => c.courtId === courtId).reduce((s, c) => s + c.cash, 0);

  return (
    <section className="card">
      <h2>{t('cashTitle')}</h2>
      <table className="mg-table">
        <thead>
          <tr>
            <th scope="col">{t('date')}</th>
            {courts.map(([id, court]) => (
              <th key={id} scope="col" className="numeric">
                {name(court)}
              </th>
            ))}
            <th scope="col" className="numeric">
              {t('total')}
            </th>
          </tr>
        </thead>
        <tbody>
          {weeks.map((week) => (
            <tr key={week}>
              <th scope="row">{t('weekOf', { date: formatDay(week, lang, 'short') })}</th>
              {courts.map(([id]) => (
                <td key={id} className="numeric">
                  {money(cell(week, id), r.currency)}
                </td>
              ))}
              <td className="numeric">{money(weekTotal(week), r.currency)}</td>
            </tr>
          ))}
          <tr className="total-row">
            <th scope="row">{t('total')}</th>
            {courts.map(([id]) => (
              <td key={id} className="numeric">
                {money(courtTotal(id), r.currency)}
              </td>
            ))}
            <td className="numeric">{money(r.cashCollected, r.currency)}</td>
          </tr>
        </tbody>
      </table>
    </section>
  );
}
```
