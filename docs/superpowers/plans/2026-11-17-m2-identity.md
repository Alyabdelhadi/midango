# M2 Identity & Access Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Customers sign in with a phone code; staff sign in with email and password in three roles (platform operator, venue manager, desk staff); every staff request is scoped to the staff member's venue. API only.

**Architecture:** One API project with feature folders (`Data/`, `Identity/`, `Venues/`). EF Core on PostgreSQL with snake_case names and migrations applied automatically in Development. Short-lived JWT access tokens (15 min) plus refresh tokens (30 days) stored as SHA-256 hashes, rotated on every use, with replay detection that revokes all of a subject's sessions. Phone codes are HMAC-hashed, single-use, expire in 5 minutes, allow 5 guesses, 60 s resend cooldown, 5 per hour. **No SMS provider yet:** in Development the code is written to the API log; any other environment refuses to send.

**Tech Stack:** .NET 10 · EF Core 10 + Npgsql provider · EFCore.NamingConventions · JwtBearer · ASP.NET Core `PasswordHasher` · libphonenumber-csharp · built-in rate limiter

**Project rules:** No automated tests. Verification is a scripted run against the live API (Task 5) plus database checks. Run commands in **PowerShell**.

**Decisions this plan locks in:**

| Topic | Decision | Why |
|---|---|---|
| Customer identity | Phone number in E.164, Saudi Arabia default region, mobiles only | Sign-in is by text message |
| Staff identity | Email + password, created by someone above them (operator → venue staff; manager → desk staff) with a temporary password | No public staff sign-up |
| Roles | `PlatformOperator` (no venue), `VenueManager`, `DeskStaff` (one venue each), enforced by a database check constraint | Venue scoping can't be forgotten |
| Phone privacy | Logs and staff-facing output use `PhoneNumber.Masked` ("•••• 4567") | Q2: staff never see full numbers |
| Deactivated staff | Lose access within 15 minutes (refresh is refused; the current access token expires) | Stateless access tokens |
| Temporary password | Login returns `mustChangePassword: true`; the Business UI (M3) forces the change | Server stays simple; the operator chose the temp password anyway |

## Endpoints delivered

| Method & path | Who | Result |
|---|---|---|
| `POST /auth/otp/request` `{phone}` | anyone (rate-limited) | 202 · 400 bad phone · 429 too soon / too many · 503 no SMS sender |
| `POST /auth/otp/verify` `{phone, code}` | anyone (rate-limited) | 200 `{accessToken, accessExpiresAt, refreshToken, profileComplete}` · 400 · 401 |
| `GET /me` · `PUT /me` `{name}` | customer | 200 `{id, phone, name}` |
| `POST /auth/refresh` `{refreshToken}` | anyone | 200 new pair · 401 |
| `POST /auth/logout` `{refreshToken}` | anyone | 204 |
| `POST /staff/auth/login` `{email, password}` | anyone (rate-limited) | 200 `{…tokens, mustChangePassword}` · 401 |
| `GET /staff/me` | staff | 200 `{id, email, displayName, role, venueId, mustChangePassword}` |
| `POST /staff/me/password` `{currentPassword, newPassword}` | staff | 200 new pair (other sessions signed out) · 400 |
| `GET /admin/venues` · `POST /admin/venues` `{nameEn, nameAr}` | platform operator | 200 list · 201 |
| `POST /admin/venues/{id}/staff` `{email, displayName, role, temporaryPassword}` | platform operator | 201 · 400 · 404 · 409 |
| `GET /venue/staff` · `POST /venue/staff` `{email, displayName, temporaryPassword}` | venue manager | 200 · 201 desk staff in own venue |

```csharp
using PhoneNumbers;

namespace Midango.Api.Identity;

/// A mobile number normalised to E.164. Anything shown to staff or written to logs uses Masked.
public readonly record struct PhoneNumber
{
    private static readonly PhoneNumberUtil Util = PhoneNumberUtil.GetInstance();

    private PhoneNumber(string e164) => E164 = e164;

    public string E164 { get; }

    /// "•••• 4567": the only form venue staff ever see (decision Q2).
    public string Masked => $"•••• {E164[^4..]}";

    /// Accepts local ("0551234567") or international ("+966551234567") input; Saudi Arabia is the default region.
    public static bool TryParse(string? input, out PhoneNumber phone)
    {
        phone = default;
        if (string.IsNullOrWhiteSpace(input)) return false;
        try
        {
            var parsed = Util.Parse(input, "SA");
            var type = Util.GetNumberType(parsed);
            if (!Util.IsValidNumber(parsed) || type is not (PhoneNumberType.MOBILE or PhoneNumberType.FIXED_LINE_OR_MOBILE))
                return false;
            phone = new PhoneNumber(Util.Format(parsed, PhoneNumberFormat.E164));
            return true;
        }
        catch (NumberParseException)
        {
            return false;
        }
    }

    /// Never print the full number by accident.
    public override string ToString() => Masked;
}
```

```csharp
using System.Buffers.Text;
using System.Security.Claims;
using System.Security.Cryptography;
using System.Text;
using Microsoft.EntityFrameworkCore;
using Microsoft.IdentityModel.JsonWebTokens;
using Microsoft.IdentityModel.Tokens;
using Midango.Api.Data;

namespace Midango.Api.Identity;

public sealed record TokenPair(string AccessToken, DateTimeOffset AccessExpiresAt, string RefreshToken);

public sealed class TokenService(MidangoDb db, JwtOptions jwt, TimeProvider clock)
{
    public static readonly TimeSpan AccessLifetime = TimeSpan.FromMinutes(15);
    public static readonly TimeSpan RefreshLifetime = TimeSpan.FromDays(30);

    public async Task<TokenPair> IssueAsync(
        SubjectKind kind, Guid subjectId, IReadOnlyList<Claim> claims, CancellationToken ct)
    {
        var now = clock.GetUtcNow();
        var rawRefresh = Base64Url.EncodeToString(RandomNumberGenerator.GetBytes(32));
        db.RefreshTokens.Add(new RefreshToken
        {
            TokenHash = Hash(rawRefresh),
            SubjectKind = kind,
            SubjectId = subjectId,
            CreatedAt = now,
            ExpiresAt = now + RefreshLifetime,
        });
        await db.SaveChangesAsync(ct);

        var accessExpires = now + AccessLifetime;
        var access = new JsonWebTokenHandler().CreateToken(new SecurityTokenDescriptor
        {
            Issuer = jwt.Issuer,
            Audience = jwt.Audience,
            IssuedAt = now.UtcDateTime,
            NotBefore = now.UtcDateTime,
            Expires = accessExpires.UtcDateTime,
            Subject = new ClaimsIdentity(claims),
            SigningCredentials = new SigningCredentials(jwt.Key(), SecurityAlgorithms.HmacSha256),
        });
        return new TokenPair(access, accessExpires, rawRefresh);
    }

    /// Spends a refresh token: returns it if it was valid, otherwise null.
    /// A token that was already spent means it was copied or replayed, so every session of that subject is revoked.
    public async Task<RefreshToken?> SpendAsync(string rawRefresh, CancellationToken ct)
    {
        var now = clock.GetUtcNow();
        var hash = Hash(rawRefresh);
        var token = await db.RefreshTokens.SingleOrDefaultAsync(t => t.TokenHash == hash, ct);
        if (token is null) return null;

        if (token.RevokedAt is not null)
        {
            await RevokeAllAsync(token.SubjectKind, token.SubjectId, ct);
            return null;
        }
        if (token.ExpiresAt <= now) return null;

        token.RevokedAt = now;
        await db.SaveChangesAsync(ct);
        return token;
    }

    public Task RevokeAsync(string rawRefresh, CancellationToken ct)
    {
        var now = clock.GetUtcNow();
        var hash = Hash(rawRefresh);
        return db.RefreshTokens
            .Where(t => t.TokenHash == hash && t.RevokedAt == null)
            .ExecuteUpdateAsync(s => s.SetProperty(t => t.RevokedAt, now), ct);
    }

    public Task RevokeAllAsync(SubjectKind kind, Guid subjectId, CancellationToken ct)
    {
        var now = clock.GetUtcNow();
        return db.RefreshTokens
            .Where(t => t.SubjectKind == kind && t.SubjectId == subjectId && t.RevokedAt == null)
            .ExecuteUpdateAsync(s => s.SetProperty(t => t.RevokedAt, now), ct);
    }

    private static string Hash(string raw) => Convert.ToHexString(SHA256.HashData(Encoding.UTF8.GetBytes(raw)));
}
```

```csharp
using System.Globalization;
using System.Security.Cryptography;
using System.Text;
using Microsoft.EntityFrameworkCore;
using Midango.Api.Data;

namespace Midango.Api.Identity;

public enum OtpRequestResult
{
    Sent,
    TooSoon,
    TooMany,
    SenderUnavailable,
}

public sealed class OtpService(
    MidangoDb db, IConfiguration config, IHostEnvironment env, ILogger<OtpService> log, TimeProvider clock)
{
    public static readonly TimeSpan CodeLifetime = TimeSpan.FromMinutes(5);
    public static readonly TimeSpan ResendCooldown = TimeSpan.FromSeconds(60);
    public const int MaxCodesPerHour = 5;
    public const int MaxAttempts = 5;

    public async Task<OtpRequestResult> RequestAsync(PhoneNumber phone, CancellationToken ct)
    {
        var now = clock.GetUtcNow();
        var hourAgo = now.AddHours(-1);
        var recent = await db.OtpChallenges
            .Where(c => c.PhoneE164 == phone.E164 && c.CreatedAt > hourAgo)
            .OrderByDescending(c => c.CreatedAt)
            .Select(c => c.CreatedAt)
            .ToListAsync(ct);
        if (recent.Count >= MaxCodesPerHour) return OtpRequestResult.TooMany;
        if (recent.Count > 0 && now - recent[0] < ResendCooldown) return OtpRequestResult.TooSoon;

        // ponytail: no SMS provider chosen yet. Development writes the code to the log; every other
        // environment refuses. Plug the provider (Unifonic / Taqnyat / Twilio) in here.
        if (!env.IsDevelopment()) return OtpRequestResult.SenderUnavailable;

        var id = Guid.CreateVersion7();
        var code = RandomNumberGenerator.GetInt32(0, 1_000_000).ToString("D6", CultureInfo.InvariantCulture);
        db.OtpChallenges.Add(new OtpChallenge
        {
            Id = id,
            PhoneE164 = phone.E164,
            CodeHash = Hash(id, code),
            CreatedAt = now,
            ExpiresAt = now + CodeLifetime,
        });
        await db.SaveChangesAsync(ct);

        log.LogWarning("DEV OTP for {Phone}: {Code}", phone.Masked, code);
        return OtpRequestResult.Sent;
    }

    /// Checks the code against the newest unexpired, unused challenge for this phone.
    public async Task<bool> VerifyAsync(PhoneNumber phone, string code, CancellationToken ct)
    {
        var now = clock.GetUtcNow();
        var challenge = await db.OtpChallenges
            .Where(c => c.PhoneE164 == phone.E164 && c.ConsumedAt == null && c.ExpiresAt > now)
            .OrderByDescending(c => c.CreatedAt)
            .FirstOrDefaultAsync(ct);
        if (challenge is null || challenge.Attempts >= MaxAttempts) return false;

        // ponytail: Attempts isn't concurrency-safe, so parallel guesses can win a few extra tries
        // out of 1,000,000. Add a row version if it is ever abused.
        challenge.Attempts++;
        var matches = CryptographicOperations.FixedTimeEquals(
            Convert.FromHexString(challenge.CodeHash), Convert.FromHexString(Hash(challenge.Id, code)));
        if (matches) challenge.ConsumedAt = now;
        await db.SaveChangesAsync(ct);
        return matches;
    }

    private string Hash(Guid challengeId, string code)
    {

            Encoding.UTF8.GetBytes(key), Encoding.UTF8.GetBytes($"{challengeId:N}:{code}")));
```

```csharp
using Microsoft.AspNetCore.Identity;
using Microsoft.EntityFrameworkCore;
using Midango.Api.Data;

namespace Midango.Api.Identity;

public sealed record StaffSummary(Guid Id, string Email, string DisplayName, StaffRole Role, bool Active);

public static class StaffAccounts
{
    public const int MinPasswordLength = 10;

    // Verified against when the email is unknown, so a wrong email takes as long as a wrong password.
    private static readonly string DummyHash =
        new PasswordHasher<StaffMember>().HashPassword(null!, "not-a-real-password-0000");

    public static string? NormaliseEmail(string? email) =>
        MailAddress.TryCreate(email?.Trim(), out var address) ? address.Address.ToLowerInvariant() : null;

    /// True when the password matches. Upgrades the stored hash if the hasher asks for it (the caller saves).
    public static bool CheckPassword(IPasswordHasher<StaffMember> hasher, StaffMember? staff, string? password)
    {
        var result = hasher.VerifyHashedPassword(staff!, staff?.PasswordHash ?? DummyHash, password ?? "");
        if (staff is null || result == PasswordVerificationResult.Failed) return false;
        if (result == PasswordVerificationResult.SuccessRehashNeeded)
            staff.PasswordHash = hasher.HashPassword(staff, password!);
        return true;
    }

    public static async Task<IResult> CreateAsync(
        MidangoDb db, IPasswordHasher<StaffMember> hasher, Guid venueId, StaffRole role,
        string? email, string? displayName, string? temporaryPassword, CancellationToken ct)
    {
        if (role == StaffRole.PlatformOperator)
            return ApiErrors.Fail(400, "Choose a role: VenueManager or DeskStaff.");
        var normalised = NormaliseEmail(email);
        if (normalised is null) return ApiErrors.Fail(400, "Enter a valid email address.");
        var name = displayName?.Trim();
        if (string.IsNullOrEmpty(name) || name.Length > 80)
            return ApiErrors.Fail(400, "Enter a name of up to 80 characters.");
        if (temporaryPassword is not { Length: >= MinPasswordLength })
            return ApiErrors.Fail(400, $"The temporary password needs at least {MinPasswordLength} characters.");
        if (!await db.Venues.AnyAsync(v => v.Id == venueId, ct))
            return ApiErrors.Fail(404, "Venue not found.");
        if (await db.Staff.AnyAsync(s => s.Email == normalised, ct))
            return ApiErrors.Fail(409, "This email already has an account.");

        var staff = new StaffMember
        {
            Email = normalised,
            DisplayName = name,
            Role = role,
            VenueId = venueId,
            MustChangePassword = true,
        };
        staff.PasswordHash = hasher.HashPassword(staff, temporaryPassword);
        db.Staff.Add(staff);
        await db.SaveChangesAsync(ct);

        return Results.Json(
            new StaffSummary(staff.Id, staff.Email, staff.DisplayName, staff.Role, staff.Active), statusCode: 201);
    }
```

```csharp
using System.Security.Claims;
using Midango.Api.Data;

namespace Midango.Api.Identity;

public static class TokenEndpoints
{
    public sealed record RefreshBody(string? RefreshToken);

    public static void MapTokenEndpoints(this IEndpointRouteBuilder app)
    {
        var auth = app.MapGroup("/auth");

        auth.MapPost("/refresh", async (RefreshBody body, TokenService tokens, MidangoDb db, CancellationToken ct) =>
        {
            if (string.IsNullOrEmpty(body.RefreshToken)) return ApiErrors.Fail(401, "Please sign in again.");
            var spent = await tokens.SpendAsync(body.RefreshToken, ct);
            if (spent is null) return ApiErrors.Fail(401, "Please sign in again.");

            // Claims are rebuilt from the database, so a role change or deactivation takes effect here.
            IReadOnlyList<Claim>? claims = spent.SubjectKind switch
            {
                SubjectKind.Customer => await db.Customers.FindAsync([spent.SubjectId], ct) is { } customer
                    ? AppClaims.For(customer)
                    : null,
                SubjectKind.Staff => await db.Staff.FindAsync([spent.SubjectId], ct) is { Active: true } staff
                    ? AppClaims.For(staff)
                    : null,
                _ => null,
            };
            if (claims is null) return ApiErrors.Fail(401, "Please sign in again.");

            return Results.Ok(await tokens.IssueAsync(spent.SubjectKind, spent.SubjectId, claims, ct));
        });

        auth.MapPost("/logout", async (RefreshBody body, TokenService tokens, CancellationToken ct) =>
        {
            if (!string.IsNullOrEmpty(body.RefreshToken)) await tokens.RevokeAsync(body.RefreshToken, ct);
            return Results.NoContent();
        });
    }
}
```
