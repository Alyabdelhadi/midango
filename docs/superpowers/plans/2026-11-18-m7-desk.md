# M7 MIDANGO Desk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The counter runs on one screen: a **Desk** page with today's bookings split into Now / Next / Earlier, a reference box (typed or scanned from the app's QR code), **Take cash & check in** in one tap, **No-show**, an **Undo** on both, a **Walk-in** button, and the cash taken so far. Today, Customers and the booking panel show the new states.

**Architecture:**
- **States on the booking, not new tables.** Check-in = `checked_in_at` + `cash_collected` (the booking's total) + who did it. No-show = a third status `NoShow` with `no_show_at`. A database check constraint keeps a checked-in booking `Confirmed`, so it can't be cancelled or marked no-show without undoing first.
- **A no-show frees the court.** The M5 exclusion constraint only covers `Confirmed`, so marking a no-show makes the court bookable again (for a walk-in). Undoing a no-show re-confirms it, and the same constraint refuses that with a 409 if the court has been taken meanwhile.
- **Undo for 15 minutes.** Cash records stay honest: after 15 minutes the API refuses the undo.
- **The QR code is the reference.** M8's app will encode the bare 6-character reference; a USB/Bluetooth scanner "types" it plus Enter into the Desk's reference box. No camera code.
- **Desk reuses what exists:** the list is `GET /venue/bookings` for today's business day; the money line comes from `GET /venue/today`; the walk-in uses M6b's new-booking dialog.

**Tech Stack:** .NET 10 · EF Core 10 / Npgsql · PostgreSQL 18 · React 19 · TypeScript · Vite 8

**Project rules:** No automated tests; Task 5 is a scripted API run plus a browser walkthrough by the controller. PowerShell. .NET packages stay on 10.x. Every string has English and Arabic. Time ranges are wrapped in `<bdi dir="ltr">` (RTL reverses them otherwise).

**Decisions this plan locks in:**

| Topic | Decision | Why |
|---|---|---|
| Payment at check-in | One action: takes the booking's full total in cash and checks in | Cash only (Q3/Q4); no partial payments yet |
| Check-in window | From 60 min before the start until 6 h after the end | Early arrivals; desks that forget to tick until the game is over |
| No-show | Any time after the start, while confirmed and not checked in; frees the court | Lets the desk sell the court to a walk-in |
| Undo | Check-in and no-show can be undone for 15 minutes | Mistap protection without editable cash history |
| Cancel after check-in | Refused (API + DB constraint): undo the check-in first | Cash taken must not vanish silently |
| Customer cancels after an early check-in | Refused: "You've already checked in at the venue." | Same rule from the app side |
| Reference lookup | `GET /venue/bookings/lookup?reference=` — any date, this venue, case-insensitive | Scanner input; staff typing lowercase |
| Home | Desk staff land on `/desk`; managers stay on `/today` | The counter is the desk role's job |

- [ ] **Step 6: Desk endpoints.** Create `Bookings/DeskEndpoints.cs`:

```csharp
using System.Security.Claims;
using Microsoft.EntityFrameworkCore;
using Midango.Api.Data;
using Midango.Api.Identity;
using Midango.Api.Venues;

namespace Midango.Api.Bookings;

/// The counter: find a booking by reference, take cash and check in, mark a no-show, undo either.
public static class DeskEndpoints
{
    public const int CheckInOpensMinutesBefore = 60;
    public const int CheckInClosesHoursAfter = 6;
    public static readonly TimeSpan UndoWindow = TimeSpan.FromMinutes(15);

    public static void MapDeskEndpoints(this IEndpointRouteBuilder app)
    {
        var desk = app.MapGroup("/venue/bookings").RequireAuthorization(Policies.VenueStaff);

        // The app's QR code holds the bare reference; a scanner types it into the Desk's box.
        desk.MapGet("/lookup", async (string? reference, ClaimsPrincipal user, MidangoDb db, CancellationToken ct) =>
        {
            var code = reference?.Trim().ToUpperInvariant();
            if (string.IsNullOrEmpty(code)) return ApiErrors.Fail(400, "Type or scan a booking reference.");
            var venue = await VenueOfAsync(db, user, ct);
            var found = await StaffBookingEndpoints.LoadAsync(db, venue,
                db.Bookings.Where(b => b.VenueId == venue.Id && b.Kind == BookingKind.Booking && b.Reference == code), ct);
            return found.Count == 0 ? ApiErrors.Fail(404, "No booking with that reference here.") : Results.Ok(found[0]);
        });

        desk.MapPost("/{id:guid}/check-in", (Guid id, ClaimsPrincipal user, MidangoDb db, TimeProvider clock, CancellationToken ct) =>
            ChangeAsync(db, user, id, ct, booking =>
            {
                if (booking.CheckedInAt is not null) return null; // already done: same answer again
                if (booking.Status != BookingStatus.Confirmed) return (409, "Only a confirmed booking can be checked in.");
                var now = clock.GetUtcNow();
                if (now < booking.StartsAt.AddMinutes(-CheckInOpensMinutesBefore))
                    return (409, $"Check-in opens {CheckInOpensMinutesBefore} minutes before the start.");
                if (now > booking.EndsAt.AddHours(CheckInClosesHoursAfter))
                    return (409, "This booking finished too long ago to check in.");
                booking.CheckedInAt = now;
                booking.CheckedInByStaffId = user.SubjectId();
                booking.CashCollected = booking.Total;
                return null;
            }));

        desk.MapPost("/{id:guid}/undo-check-in", (Guid id, ClaimsPrincipal user, MidangoDb db, TimeProvider clock, CancellationToken ct) =>
            ChangeAsync(db, user, id, ct, booking =>
            {
                if (booking.CheckedInAt is not { } at) return null;
                if (clock.GetUtcNow() - at > UndoWindow) return (409, "A check-in can only be undone within 15 minutes.");
                booking.CheckedInAt = null;
                booking.CheckedInByStaffId = null;
                booking.CashCollected = null;
                return null;
            }));

        desk.MapPost("/{id:guid}/no-show", (Guid id, ClaimsPrincipal user, MidangoDb db, TimeProvider clock, CancellationToken ct) =>
            ChangeAsync(db, user, id, ct, booking =>
            {
                if (booking.Status == BookingStatus.NoShow) return null;
                if (booking.Status != BookingStatus.Confirmed) return (409, "Only a confirmed booking can be marked as a no-show.");
                if (booking.CheckedInAt is not null) return (409, "This customer has checked in. Undo the check-in first.");
                var now = clock.GetUtcNow();
                if (now < booking.StartsAt) return (409, "Wait until the booking has started.");
                booking.Status = BookingStatus.NoShow;
                booking.NoShowAt = now;
                return null;
            }));

        desk.MapPost("/{id:guid}/undo-no-show", (Guid id, ClaimsPrincipal user, MidangoDb db, TimeProvider clock, CancellationToken ct) =>
            ChangeAsync(db, user, id, ct, booking =>
            {
                if (booking.Status != BookingStatus.NoShow) return null;
                if (clock.GetUtcNow() - booking.NoShowAt > UndoWindow) return (409, "A no-show can only be undone within 15 minutes.");
                booking.Status = BookingStatus.Confirmed;
                booking.NoShowAt = null;
                return null;
            }));
    }

    private static Task<Venue> VenueOfAsync(MidangoDb db, ClaimsPrincipal user, CancellationToken ct) =>
        db.Venues.AsNoTracking().SingleAsync(v => v.Id == user.StaffVenueId()!.Value, ct);

    /// Loads one of the caller's venue bookings, applies `change` (which returns an error or null), saves and
    /// returns the booking. Re-confirming a no-show goes through the exclusion constraint like any booking.
    private static async Task<IResult> ChangeAsync(
        MidangoDb db, ClaimsPrincipal user, Guid id, CancellationToken ct, Func<Booking, (int Status, string Title)?> change)
    {
        var venue = await VenueOfAsync(db, user, ct);
        var booking = await db.Bookings.SingleOrDefaultAsync(b => b.Id == id && b.VenueId == venue.Id, ct);
        if (booking is null) return ApiErrors.Fail(404, "Booking not found.");
        if (booking.Kind == BookingKind.Block) return ApiErrors.Fail(400, "A block has nobody to check in.");

        if (change(booking) is { } error) return ApiErrors.Fail(error.Status, error.Title);
        if (await BookingStore.SaveAsync(db, [], ct) is not null)
            return ApiErrors.Fail(409, "The court has been booked again since. The no-show stays.");

        return Results.Ok((await StaffBookingEndpoints.LoadAsync(db, venue, db.Bookings.Where(b => b.Id == id), ct)).Single());
    }
}
```

- [ ] **Step 3: Undo in the toast.** Replace `lib/useToast.tsx`:

```tsx
import { useCallback, useEffect, useState } from 'react';
import { Notice } from '../components/Notice';
import { errorText } from './api';
import { useI18n } from './i18n';

type Tone = 'error' | 'success';
type Toast = { tone: Tone; text: string; undo?: () => Promise<unknown> };

/** Success messages fade (5 s, or 10 s when they offer Undo); errors stay until the next action.
 *  Render `view` once per page. */
export function useToast() {
  const { t } = useI18n();
  const [toast, setToast] = useState<Toast>();

  useEffect(() => {
    if (toast?.tone !== 'success') return;
    const timer = setTimeout(() => setToast(undefined), toast.undo ? 10_000 : 5000);
    return () => clearTimeout(timer);
  }, [toast]);

  const show = useCallback(
    (tone: Tone, text: string, undo?: () => Promise<unknown>) => setToast({ tone, text, undo }),
    [],
  );

  async function runUndo(undo: () => Promise<unknown>) {
    setToast(undefined);
    try {
      await undo();
      setToast({ tone: 'success', text: t('undone') });
    } catch (err) {
      setToast({ tone: 'error', text: errorText(err) });
    }
  }

  const view = (
    <div className="toast-region" aria-live="polite">
      {toast && (
        <Notice tone={toast.tone}>
          {toast.text}
          {toast.undo && (
            <button type="button" className="toast-undo" onClick={() => void runUndo(toast.undo!)}>
              {t('undo')}
            </button>
          )}
        </Notice>
      )}
    </div>
  );
  return { show, view };
}
```

- [ ] **Step 5: Desk actions.** Create `components/DeskActions.tsx`:

```tsx
import { useState } from 'react';
import { api, errorText } from '../lib/api';
import { useI18n } from '../lib/i18n';
import type { StaffBooking } from '../lib/types';
import { Button } from './Button';

const HOUR = 3_600_000;

/** Undo for the action just taken; the page reloads its data after it. */
export type Undo = () => Promise<unknown>;

/** The counter's next step for a booking, from its state: take cash & check in, and/or no-show.
 *  Renders nothing when neither applies (block, cancelled, checked in, no-show, outside the window). */
export function DeskActions({ booking: b, onDone }: { booking: StaffBooking; onDone: (message: string, undo: Undo) => void }) {
  const { t, money } = useI18n();
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState<string>();
  if (b.kind === 'Block' || b.status !== 'Confirmed' || b.checkedInAt) return null;

  // eslint-disable-next-line react/purity -- the buttons follow the clock; the page re-renders on reload
  const now = Date.now();
  const start = new Date(b.startsAt).getTime();
  const end = new Date(b.endsAt).getTime();
  const canCheckIn = now >= start - HOUR && now <= end + 6 * HOUR;
  const canNoShow = now >= start;
  if (!canCheckIn && !canNoShow) return null;

  const amount = money(b.total, b.currency);
  const who = b.customerName ?? '';

  async function run(action: string, undoAction: string, message: string) {
    setBusy(true);
    setError(undefined);
    try {
      await api(`/venue/bookings/${b.id}/${action}`, { method: 'POST' });
      onDone(message, () => api(`/venue/bookings/${b.id}/${undoAction}`, { method: 'POST' }));
    } catch (err) {
      setError(errorText(err));
    } finally {
      setBusy(false);
    }
  }

  return (
    <div className="desk-actions">
      {canCheckIn && (
        <Button disabled={busy} onClick={() => void run('check-in', 'undo-check-in', t('checkedInNotice', { name: who, amount }))}>
          {t('takeCashCheckIn', { amount })}
        </Button>
      )}
      {canNoShow && (
        <Button variant="secondary" disabled={busy} onClick={() => void run('no-show', 'undo-no-show', t('noShowNotice', { name: who }))}>
          {t('markNoShow')}
        </Button>
      )}
      {error && (
        <span className="desk-error" role="alert">
          {error}
        </span>
      )}
    </div>
  );
}
```

/** The counter: today's bookings as Now / Next / Earlier, a reference box for typed or scanned codes,
 *  one-tap check-in, no-show, walk-ins and the cash taken so far. Refreshes every 30 s. */
export function DeskPage() {
  const { t, money } = useI18n();
  const today = useLoad(() => api<Today>('/venue/today'));
  const toast = useToast();
  const [openBooking, setOpenBooking] = useState<StaffBooking>();
  const [walkIn, setWalkIn] = useState<{ schedule: Schedule; at: NewAt }>();
  const [reference, setReference] = useState('');
  const [lookupError, setLookupError] = useState<string>();
  const [version, setVersion] = useState(0);
  const reloadToday = today.reload;

  useEffect(() => {
    const timer = setInterval(() => {
      reloadToday();
      setVersion((v) => v + 1);
    }, 30_000);
    return () => clearInterval(timer);
  }, [reloadToday]);

  function reloadAll() {
    reloadToday();
    setVersion((v) => v + 1);
  }

  function done(message: string, undo?: Undo) {
    setOpenBooking(undefined);
    setWalkIn(undefined);
    toast.show('success', message, undo && (async () => { await undo(); reloadAll(); }));
    reloadAll();
  }

  async function lookUp(e: FormEvent) {
    e.preventDefault();
    setLookupError(undefined);
    const code = reference.trim();
    if (!code) return;
    try {
      setOpenBooking(await api<StaffBooking>(`/venue/bookings/lookup?reference=${encodeURIComponent(code)}`));
      setReference('');
    } catch (err) {
      setLookupError(errorText(err));
    }
  }

  async function startWalkIn() {
    try {
      const schedule = await api<Schedule>('/venue/schedule');
      const starts = slotStarts(schedule.from, schedule.to);
      // The half hour we're in now, on the first court that's free for it.
      const now = Date.now();
      const start = [...starts].reverse().find((s) => new Date(s).getTime() <= now) ?? starts[0];
      if (!schedule.open || !start || schedule.courts.length === 0) return toast.show('error', t('closedToday'));
      const busy = (courtId: string) =>
        schedule.bookings.some(
          (b) => b.courtId === courtId && minutesBetween(b.startsAt, start) < b.minutes && minutesBetween(start, b.startsAt) < 30,
        );
      const court = schedule.courts.find((c) => !busy(c.id)) ?? schedule.courts[0];
      setWalkIn({ schedule, at: { courtId: court.id, start } });
    } catch (err) {
      toast.show('error', errorText(err));
    }
  }

  if (today.error) {
    return (
      <div className="page">
        <Notice tone="error">{today.error}</Notice>
      </div>
    );
  }
  if (!today.data) return <p className="page-loading">{t('loading')}</p>;
  const d = today.data;

  return (
    <div className="page">
      <PageHeader title={t('navDesk')} action={<Button onClick={() => void startWalkIn()}>{t('newWalkIn')}</Button>} />
      <form className="search-form" onSubmit={lookUp} role="search">
        <Field label={t('lookupLabel')} hint={t('lookupHint')}>
          <input
            autoFocus
            autoComplete="off"
            spellCheck={false}
            dir="ltr"
            maxLength={12}
            value={reference}
            onChange={(e) => setReference(e.target.value)}
          />
        </Field>
        <Button type="submit" variant="secondary">
          {t('search')}
        </Button>
      </form>
      {lookupError && <Notice tone="error">{lookupError}</Notice>}
      <p className="desk-summary">
        {t('cashSummary', { taken: money(d.cashCollected, d.currency), expected: money(d.cashExpected, d.currency) })}
      </p>
      <DeskLists key={`${d.date}|${version}`} date={d.date} onOpen={setOpenBooking} onDone={done} />

      <BookingPanel booking={openBooking} onDone={done} onClose={() => setOpenBooking(undefined)} />
      {walkIn && (
        <NewBookingDialog schedule={walkIn.schedule} at={walkIn.at} onDone={done} onClose={() => setWalkIn(undefined)} />
      )}
      {toast.view}
    </div>
  );
}

function DeskLists({
  date,
  onOpen,
  onDone,
}: {
  date: string;
  onOpen: (b: StaffBooking) => void;
  onDone: (message: string, undo?: Undo) => void;
}) {
  const { t } = useI18n();
  const list = useLoad(() => api<StaffBooking[]>(`/venue/bookings?from=${date}`));
  if (list.error) return <Notice tone="error">{list.error}</Notice>;
  if (!list.data) return <p className="page-loading">{t('loading')}</p>;

  // eslint-disable-next-line react/purity -- grouping follows the clock; the page reloads every 30 s
  const now = Date.now();
  const rows = list.data.filter((b) => b.status !== 'Cancelled');
  const nowRows = rows.filter((b) => new Date(b.startsAt).getTime() <= now && new Date(b.endsAt).getTime() > now);
  const nextRows = rows.filter((b) => new Date(b.startsAt).getTime() > now);
  const earlierRows = rows.filter((b) => new Date(b.endsAt).getTime() <= now);

  const listOf = (items: StaffBooking[]) => (
    <ul className="desk-list">
      {items.map((b) => (
        <DeskRow key={b.id} booking={b} onOpen={onOpen} onDone={onDone} />
      ))}
    </ul>
  );

  return (
    <>
      <section className="card">
        <h2>{t('sectionNow')}</h2>
        {nowRows.length === 0 ? <p className="empty">{t('nothingNow')}</p> : listOf(nowRows)}
      </section>
      <section className="card">
        <h2>{t('sectionNext')}</h2>
        {nextRows.length === 0 ? <p className="empty">{t('nothingNext')}</p> : listOf(nextRows)}
      </section>
      {earlierRows.length > 0 && (
        <details className="card desk-earlier">
          <summary>{t('sectionEarlier', { n: earlierRows.length })}</summary>
          {listOf(earlierRows)}
        </details>
      )}
    </>
  );
}
