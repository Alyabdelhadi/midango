# M4 Prices Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every court has a price per hour, and venue managers can set peak and off-peak prices by day and time (including past midnight), applying one board to several courts at once. Anyone at the venue can check exactly what a booking costs, including the VAT portion.

**Architecture:**
- **Data:** `Court.HourlyPrice` is the base price. `PriceBand` rows (court, day, from, to, price per hour) override it during their period, and `To ≤ From` means the period runs past midnight into the next day.
- **Calculation:** one pure static calculator, `Catalog/Pricing.cs`, walks the booking in 15-minute slices on a 7-day circle, picks the rate for each slice, and merges equal neighbours into segments. M5 (bookings) reuses it unchanged.
- **VAT and currency:** prices are VAT-inclusive (what the customer pays). The venue holds its currency (`SAR`) and VAT rate (15), and a quote shows the total, the net amount and the VAT portion.
- **Admin:** a price field on the court form; a new Prices page (manager edits; desk staff read-only) with the peak/off-peak table and a price check.

**Tech Stack:** .NET 10 / EF Core 10 (numeric columns) · React 19 admin from M3b

**Project rules:** No automated tests; Task 3 is a scripted check against the live API with exact expected amounts, and Task 5 is a browser walkthrough by the controller. PowerShell. .NET packages stay on 10.x.

**Decisions this plan locks in:**

| Topic | Decision | Why |
|---|---|---|
| Price entry | Per hour, VAT-inclusive, 1–10,000 with at most 2 decimals | Matches what venues already quote and what customers pay |
| Base price | Required on every court (no unpriced courts) | A bookable court with no price must be impossible |
| Peak/off-peak | Periods per day on quarter-hour marks; they may not overlap (checked across midnight); outside them the court's base price applies | Predictable, and easy to read back |
| Applying a board | The same periods can be saved to several courts in one go; each court keeps its own base price | Venues usually price same-sport courts alike, but panoramic courts cost more |
| Rounding | Amount per slice unrounded; total rounded to 2 decimals (half away from zero); net = total ÷ (1 + VAT%), rounded; VAT = total − net | The VAT portion always adds up to the total exactly |
| Quote | `GET /venue/quote?courtId&day&time&minutes`, where minutes must be one of the sport's booking lengths | The price check now; the booking engine (M5) wraps the same calculator |

## Endpoints delivered / changed

| Method & path | Who | Change |
|---|---|---|
| `POST/PUT /venue/courts…` | venue manager | Body gains `hourlyPrice` (required) |
| `GET /venue` (and every venue write) | venue staff | Response gains `currencyCode`, `vatPercent`; each court gains `hourlyPrice` and `bands` |
| `PUT /venue/prices` `{courtIds, bands[]}` | venue manager | Replaces the peak/off-peak periods of the listed courts |
| `GET /venue/quote?courtId&day&time&minutes` | venue manager, desk staff | `{total, net, vat, vatPercent, currency, segments[]}` |

```csharp
namespace Midango.Api.Catalog;

public sealed record PriceBandRule(DayOfWeek Day, TimeOnly From, TimeOnly To, decimal HourlyPrice);

public sealed record PriceSegment(TimeOnly From, TimeOnly To, decimal HourlyPrice, decimal Amount);

public sealed record PriceQuote(decimal Total, decimal Net, decimal Vat, IReadOnlyList<PriceSegment> Segments);

/// The one place a booking's price is worked out (price check now, bookings in M5).
public static class Pricing
{
    private const int MinutesPerDay = 1440;
    private const int MinutesPerWeek = 7 * MinutesPerDay;
    private const int SliceMinutes = 15;

    /// Prices `minutes` starting at `start` on `day`. Each 15-minute slice uses the period it starts in,
    /// or the court's base price outside every period. All prices are VAT-inclusive.
    public static PriceQuote Calculate(
        decimal basePrice, IReadOnlyList<PriceBandRule> bands, DayOfWeek day, TimeOnly start, int minutes, decimal vatPercent)
    {
        var startOfWeek = (int)day * MinutesPerDay + start.Hour * 60 + start.Minute;
        var segments = new List<PriceSegment>();

        for (var offset = 0; offset < minutes; offset += SliceMinutes)
        {
            var length = Math.Min(SliceMinutes, minutes - offset);
            var rate = RateAt((startOfWeek + offset) % MinutesPerWeek, basePrice, bands);
            var amount = rate * length / 60m;
            var to = start.AddMinutes(offset + length);

            if (segments.Count > 0 && segments[^1].HourlyPrice == rate)
                segments[^1] = segments[^1] with { To = to, Amount = segments[^1].Amount + amount };
            else
                segments.Add(new PriceSegment(start.AddMinutes(offset), to, rate, amount));
        }

        var total = Round(segments.Sum(s => s.Amount));
        var net = Round(total / (1 + vatPercent / 100m));
        return new PriceQuote(total, net, total - net, segments.Select(s => s with { Amount = Round(s.Amount) }).ToList());
    }

    /// Price per hour at a minute of the week (Sunday 00:00 = 0).
    public static decimal RateAt(int minuteOfWeek, decimal basePrice, IReadOnlyList<PriceBandRule> bands)
    {
        foreach (var band in bands)
        {
            var (start, length) = Span(band);
            if (Distance(start, minuteOfWeek) < length) return band.HourlyPrice;
        }
        return basePrice;
    }

    /// True when two periods share any minute, including periods that run past midnight.
    public static bool Overlaps(PriceBandRule a, PriceBandRule b)
    {
        var (startA, lengthA) = Span(a);
        var (startB, lengthB) = Span(b);
        return Distance(startA, startB) < lengthA || Distance(startB, startA) < lengthB;
    }

    public static bool ValidPrice(decimal price) => price is >= 1m and <= 10_000m && decimal.Round(price, 2) == price;

    public static bool OnQuarterHour(TimeOnly time) => time.Minute % SliceMinutes == 0 && time.Second == 0 && time.Millisecond == 0;

    /// Start minute of the week and length in minutes. To <= From wraps past midnight.
    private static (int Start, int Length) Span(PriceBandRule band)
    {
        var from = band.From.Hour * 60 + band.From.Minute;
        var to = band.To.Hour * 60 + band.To.Minute;
        var length = (to - from + MinutesPerDay) % MinutesPerDay;
        return ((int)band.Day * MinutesPerDay + from, length == 0 ? MinutesPerDay : length);
    }

    /// Minutes forward from `from` to `to` around the week.
    private static int Distance(int from, int to) => ((to - from) % MinutesPerWeek + MinutesPerWeek) % MinutesPerWeek;

    private static decimal Round(decimal value) => Math.Round(value, 2, MidpointRounding.AwayFromZero);
}
```

```csharp
using System.Security.Claims;
using Microsoft.EntityFrameworkCore;
using Midango.Api.Data;
using Midango.Api.Identity;

namespace Midango.Api.Catalog;

public static class PriceEndpoints
{
    public sealed record BandInput(DayOfWeek Day, TimeOnly From, TimeOnly To, decimal HourlyPrice);

    public sealed record PricesInput(Guid[]? CourtIds, BandInput[]? Bands);

    public sealed record QuoteDto(
        Guid CourtId, DayOfWeek Day, TimeOnly Start, int Minutes, decimal Total, decimal Net, decimal Vat,
        decimal VatPercent, string Currency, IReadOnlyList<PriceSegment> Segments);

    public static void MapPriceEndpoints(this IEndpointRouteBuilder app)
    {
        // Replaces the peak/off-peak periods of every listed court with the same board.
        app.MapPut("/venue/prices", async (PricesInput input, ClaimsPrincipal user, MidangoDb db, CancellationToken ct) =>
        {
            var venueId = user.StaffVenueId()!.Value;
            var courtIds = input.CourtIds?.Distinct().ToArray() ?? [];
            if (courtIds.Length == 0) return ApiErrors.Fail(400, "Choose at least one court.");
            var owned = await db.Courts.CountAsync(c => courtIds.Contains(c.Id) && c.VenueId == venueId, ct);
            if (owned != courtIds.Length) return ApiErrors.Fail(404, "Court not found.");

            var bands = input.Bands ?? [];
            if (ValidateBands(bands) is { } error) return ApiErrors.Fail(400, error);

            await using var tx = await db.Database.BeginTransactionAsync(ct);
            await db.PriceBands.Where(b => courtIds.Contains(b.CourtId)).ExecuteDeleteAsync(ct);
            db.PriceBands.AddRange(courtIds.SelectMany(courtId => bands.Select(b => new PriceBand
            {
                CourtId = courtId,
                Day = b.Day,
                From = b.From,
                To = b.To,
                HourlyPrice = b.HourlyPrice,
            })));
            await db.SaveChangesAsync(ct);
            await tx.CommitAsync(ct);

            return Results.Ok(await VenueEndpoints.LoadAsync(db, venueId, ct));
        }).RequireAuthorization(Policies.VenueManager);

        // What a booking costs. Desk staff use this at the counter.
        app.MapGet("/venue/quote", async (
            Guid courtId, DayOfWeek day, TimeOnly time, int minutes, ClaimsPrincipal user, MidangoDb db, CancellationToken ct) =>
        {
            var venueId = user.StaffVenueId()!.Value;
            var court = await db.Courts.AsNoTracking().SingleOrDefaultAsync(c => c.Id == courtId && c.VenueId == venueId, ct);
            if (court is null) return ApiErrors.Fail(404, "Court not found.");
            if (!Enum.IsDefined(day) || !Pricing.OnQuarterHour(time))
                return ApiErrors.Fail(400, "Choose a day and a start time on the quarter hour.");

            var durations = await db.SportCategories.Where(c => c.Id == court.CategoryId).Select(c => c.DurationsMinutes).SingleAsync(ct);
            if (!durations.Contains(minutes)) return ApiErrors.Fail(400, "Choose one of this sport's booking lengths.");

            var venue = await db.Venues.AsNoTracking().SingleAsync(v => v.Id == venueId, ct);
            var bands = await db.PriceBands.AsNoTracking().Where(b => b.CourtId == courtId)
                .Select(b => new PriceBandRule(b.Day, b.From, b.To, b.HourlyPrice)).ToListAsync(ct);

            var quote = Pricing.Calculate(court.HourlyPrice, bands, day, time, minutes, venue.VatPercent);
            return Results.Ok(new QuoteDto(
                court.Id, day, time, minutes, quote.Total, quote.Net, quote.Vat, venue.VatPercent, venue.CurrencyCode, quote.Segments));
        }).RequireAuthorization(Policies.VenueStaff);
    }

    private static string? ValidateBands(BandInput[] bands)
    {
        if (bands.Length > 50) return "Use at most 50 price periods.";
        foreach (var band in bands)
        {
            if (!Enum.IsDefined(band.Day)) return "Choose a day for every price period.";
            if (band.From == band.To) return "A price period can't start and end at the same time.";
            if (!Pricing.OnQuarterHour(band.From) || !Pricing.OnQuarterHour(band.To))
                return "Price periods start and end on the quarter hour (:00, :15, :30, :45).";
            if (!Pricing.ValidPrice(band.HourlyPrice))
                return "Enter a price per hour between 1 and 10,000, with at most 2 decimals.";
        }

        var rules = bands.Select(b => new PriceBandRule(b.Day, b.From, b.To, b.HourlyPrice)).ToList();
        for (var i = 0; i < rules.Count; i++)
        for (var j = i + 1; j < rules.Count; j++)
        {
            if (Pricing.Overlaps(rules[i], rules[j]))
                return $"Two price periods overlap ({rules[i].Day} {rules[i].From:HH\\:mm} and {rules[j].Day} {rules[j].From:HH\\:mm}).";
        }
        return null;
    }
}
```

```tsx
import { useState, type FormEvent } from 'react';
import { Button } from '../components/Button';
import { Field } from '../components/Field';
import { Notice } from '../components/Notice';
import { PageHeader } from '../components/PageHeader';
import { api, errorText } from '../lib/api';
import { useI18n } from '../lib/i18n';
import { DAY_KEY, DAYS, type Band, type Category, type Day, type Quote, type Venue } from '../lib/types';
import { useLoad } from '../lib/useLoad';

/** One editable row: the same period and price on several days. */
type Row = { key: string; days: Day[]; from: string; to: string; price: string };

function rowsFromBands(bands: Band[]): Row[] {
  const rows = new Map<string, Row>();
  for (const band of bands) {
    const id = `${band.from}|${band.to}|${band.hourlyPrice}`;
    const row = rows.get(id) ?? {
      key: crypto.randomUUID(),
      days: [],
      from: band.from.slice(0, 5),
      to: band.to.slice(0, 5),
      price: String(band.hourlyPrice),
    };
    row.days.push(band.day);
    rows.set(id, row);
  }
  return [...rows.values()].map((row) => ({ ...row, days: DAYS.filter((d) => row.days.includes(d)) }));
}

function bandsFromRows(rows: Row[]): Band[] {
  return rows.flatMap((row) =>
    row.days.map((day) => ({ day, from: `${row.from}:00`, to: `${row.to}:00`, hourlyPrice: Number(row.price) })),
  );
}

const boardKey = (bands: Band[]) =>
  bands.map((b) => `${b.day}|${b.from}|${b.to}|${b.hourlyPrice}`).sort().join(',');

export function PricesPage({ canEdit }: { canEdit: boolean }) {
  const { t } = useI18n();
  const venue = useLoad(() => api<Venue>('/venue'));
  const categories = useLoad(() => api<Category[]>('/categories'));

  if (venue.error) {
    return (
      <div className="page">
        <Notice tone="error">{venue.error}</Notice>
      </div>
    );
  }
  if (!venue.data || !categories.data) return <p className="page-loading">{t('loading')}</p>;

  return (
    <div className="page">
      <PageHeader title={t('navPrices')} />
      <p className="page-intro">{t('pricesIntro')}</p>
      {venue.data.courts.length === 0 ? (
        <p className="empty">{t('noCourts')}</p>
      ) : (
        <>
          <PriceBoard venue={venue.data} canEdit={canEdit} onSaved={venue.setData} />
          <PriceCheck venue={venue.data} categories={categories.data} />
        </>
      )}
    </div>
  );
}

function PriceBoard({ venue, canEdit, onSaved }: { venue: Venue; canEdit: boolean; onSaved: (venue: Venue) => void }) {
  const { t, name, money } = useI18n();
  const [selected, setSelected] = useState<string[]>(() => venue.courts.map((c) => c.id));
  const [rows, setRows] = useState<Row[]>(() => rowsFromBands(venue.courts[0]?.bands ?? []));
  const [message, setMessage] = useState<{ tone: 'error' | 'success'; text: string }>();
  const [busy, setBusy] = useState(false);

  const selectedCourts = venue.courts.filter((c) => selected.includes(c.id));
  const boardsDiffer = selectedCourts.some((c) => boardKey(c.bands) !== boardKey(selectedCourts[0].bands));
  const update = (key: string, patch: Partial<Row>) => setRows((list) => list.map((r) => (r.key === key ? { ...r, ...patch } : r)));
  const toggle = <T,>(list: T[], item: T) => (list.includes(item) ? list.filter((x) => x !== item) : [...list, item]);

  async function save(e: FormEvent) {
    e.preventDefault();
    if (selected.length === 0) return setMessage({ tone: 'error', text: t('chooseCourts') });
    setBusy(true);
    setMessage(undefined);
    try {
      const updated = await api<Venue>('/venue/prices', {
        method: 'PUT',
        body: { courtIds: selected, bands: bandsFromRows(rows.filter((r) => r.days.length > 0)) },
      });
      onSaved(updated);
      setMessage({ tone: 'success', text: t('saved') });
    } catch (err) {
      setMessage({ tone: 'error', text: errorText(err) });
    } finally {
      setBusy(false);
    }
  }

  return (
    <form className="card" onSubmit={save}>
      <fieldset className="mg-fieldset" disabled={!canEdit}>
        <legend>{t('pricesAppliesTo')}</legend>
        <div className="chip-row">
          {venue.courts.map((court) => (
            <label key={court.id} className="check-chip">
              <input
                type="checkbox"
                checked={selected.includes(court.id)}
                onChange={() => setSelected((list) => toggle(list, court.id))}
              />
              {name(court)} · {t('perHour', { price: money(court.hourlyPrice, venue.currencyCode) })}
            </label>
          ))}
        </div>
        {boardsDiffer && <Notice tone="info">{t('pricesDiffer')}</Notice>}
      </fieldset>

      <fieldset className="mg-fieldset" disabled={!canEdit}>
        <legend>{t('peakPeriods')}</legend>
        {rows.length === 0 && <p className="empty">{t('noPeriods')}</p>}
        {rows.map((row) => (
          <div key={row.key} className="period-row">
            <div className="chip-row" role="group" aria-label={t('days')}>
              {DAYS.map((day) => (
                <label key={day} className="check-chip">
                  <input
                    type="checkbox"
                    checked={row.days.includes(day)}
                    onChange={() => update(row.key, { days: DAYS.filter((d) => toggle(row.days, day).includes(d)) })}
                  />
                  {t(DAY_KEY[day])}
                </label>
              ))}
            </div>
            <div className="period-fields">
              <Field label={t('fromTime')}>
                <input type="time" step={900} required value={row.from} onChange={(e) => update(row.key, { from: e.target.value })} />
              </Field>
              <Field label={t('toTime')} hint={row.to <= row.from ? t('closesNextDay') : undefined}>
                <input type="time" step={900} required value={row.to} onChange={(e) => update(row.key, { to: e.target.value })} />
              </Field>
              <Field label={t('pricePerHour')}>
                <input
                  type="number"
                  required
                  min={1}
                  max={10000}
                  step="0.01"
                  inputMode="decimal"
                  value={row.price}
                  onChange={(e) => update(row.key, { price: e.target.value })}
                />
              </Field>
              {canEdit && (
                <Button variant="text" onClick={() => setRows((list) => list.filter((r) => r.key !== row.key))}>
                  {t('remove')}
                </Button>
              )}
            </div>
          </div>
        ))}
        {canEdit && (
          <div>
            <Button
              variant="secondary"
              onClick={() =>
                setRows((list) => [...list, { key: crypto.randomUUID(), days: [], from: '18:00', to: '23:00', price: '' }])
              }
            >
              {t('addPeriod')}
            </Button>
          </div>
        )}
      </fieldset>

      {message && <Notice tone={message.tone}>{message.text}</Notice>}
      {canEdit && (
        <div className="form-actions">
          <Button type="submit" disabled={busy}>
            {t('savePrices')}
          </Button>
        </div>
      )}
    </form>
  );
}

function PriceCheck({ venue, categories }: { venue: Venue; categories: Category[] }) {
  const { t, name, money } = useI18n();
  const [courtId, setCourtId] = useState(venue.courts[0].id);
  const [day, setDay] = useState<Day>('Friday');
  const [time, setTime] = useState('20:00');
  const [minutes, setMinutes] = useState(0);
  const [quote, setQuote] = useState<Quote>();
  const [error, setError] = useState<string>();

  const court = venue.courts.find((c) => c.id === courtId);
  const durations = categories.find((c) => c.id === court?.categoryId)?.durationsMinutes ?? [60];
  const length = durations.includes(minutes) ? minutes : durations[0];

  async function check(e: FormEvent) {
    e.preventDefault();
    setError(undefined);
    try {
      const query = new URLSearchParams({ courtId, day, time, minutes: String(length) });
      setQuote(await api<Quote>(`/venue/quote?${query}`));
    } catch (err) {
      setQuote(undefined);
      setError(errorText(err));
    }
  }

  return (
    <section className="card">
      <h2>{t('priceCheck')}</h2>
      <p className="page-intro">{t('priceCheckIntro')}</p>
      <form className="period-fields" onSubmit={check}>
        <Field label={t('court')}>
          <select value={courtId} onChange={(e) => setCourtId(e.target.value)}>
            {venue.courts.map((c) => (
              <option key={c.id} value={c.id}>
                {name(c)}
              </option>
            ))}
          </select>
        </Field>
        <Field label={t('day')}>
          <select value={day} onChange={(e) => setDay(e.target.value as Day)}>
            {DAYS.map((d) => (
              <option key={d} value={d}>
                {t(DAY_KEY[d])}
              </option>
            ))}
          </select>
        </Field>
        <Field label={t('startTime')}>
          <input type="time" step={900} required value={time} onChange={(e) => setTime(e.target.value)} />
        </Field>
        <Field label={t('length')}>
          <select value={length} onChange={(e) => setMinutes(Number(e.target.value))}>
            {durations.map((m) => (
              <option key={m} value={m}>
                {t('minutesShort', { m })}
              </option>
            ))}
          </select>
        </Field>
        <Button type="submit">{t('check')}</Button>
      </form>
      {error && <Notice tone="error">{error}</Notice>}
      {quote && (
        <div className="quote">
          <p className="quote-line">
            {t('quoteLine', {
              day: t(DAY_KEY[quote.day]),
              time: quote.start.slice(0, 5),
              minutes: quote.minutes,
              total: money(quote.total, quote.currency),
            })}
          </p>
          <p className="hours-note">
            {t('quoteVat', { vat: money(quote.vat, quote.currency), percent: quote.vatPercent })}

                  to: s.to.slice(0, 5),
                  rate: money(s.hourlyPrice, quote.currency),
                  amount: money(s.amount, quote.currency),
                })}
              </li>
            ))}
          </ul>
        </div>
      )}
    </section>
  );
}
```
